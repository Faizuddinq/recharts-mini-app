## Installation

### Prerequisites

- Node.js installed
- npm or yarn as a package manager

### Steps

1. Clone this repository:

   ```bash
   git clone https://github.com/Faizuddinq/recharts-mini-app
   cd recharts-showcase
   ```

2. Install dependencies:

   ```bash
   npm install
   # or
   yarn install
   ```

3. Start the development server:

   ```bash
   npm start
   # or
   yarn start
   ```

## Usage

This project is built using React.js and showcases three types of charts using Recharts.js. The following components are included:

- Area Chart
- Bar Chart
- Line Chart

The charts are customizable and demonstrate basic interactions like tooltips, legends, and responsive behavior.
